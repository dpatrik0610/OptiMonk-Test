# Funnel Analytics Mini-App

A Vue 3 application for visualizing funnel performance in popup campaigns.
The app focuses on identifying where users drop off in multi-step flows and highlighting the weakest step in each campaign.

## Getting Started
The app runs as a local development server using Vite.

### Prerequisites

* npm

### Installation

```bash
cd .\optimonk-test\
npm install
```

### Development

```bash
npm run dev
```

Open the app:

```
http://localhost:5173
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
